# Rules for working on this repo

- NEVER spend money or credits without the owner's explicit permission for that specific run.
  This covers ElevenLabs (speech, image, video), OpenAI images, Anthropic, and any other paid service.
  Price it first (estimate only), tell the owner the cost, and wait for a yes.
- No ElevenLabs video generation unless the owner approves it as able to make a real cartoon.
- The owner does not want 2D cut-out puppets with only mouths opening and closing.
